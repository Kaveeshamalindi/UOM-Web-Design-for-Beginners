# UOM Web Design for Beginners 🌐

A collection of practical exercises, activities, and projects completed while learning **Web Design for Beginners** through the University of Moratuwa (UOM).

This repository documents my learning journey in the fundamentals of **HTML, CSS, and JavaScript**, with hands-on practice in web page design, user interfaces, the DOM, and JavaScript projects.

---

## 📚 Topics Covered

* HTML fundamentals
* CSS styling
* CSS Box Model
* User Interface (UI) design
* JavaScript fundamentals
* DOM manipulation
* JavaScript projects
* Web page structure and layout
* Responsive and interactive web design
* Final web design project

---

## 🛠️ Technologies Used

* **HTML5** – Structure and content
* **CSS3** – Styling and layout
* **JavaScript** – Interactivity and dynamic functionality
* **Git & GitHub** – Version control and project management

---

## 🎯 Learning Objectives

Through this repository, I practiced how to:

* Build structured web pages using HTML
* Style web pages using CSS
* Understand the CSS Box Model
* Create basic user interfaces
* Use JavaScript to add interactivity
* Manipulate HTML elements using the DOM
* Develop small web projects
* Organize and manage projects using GitHub

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/Kaveeshamalindi/UOM-Web-Design-for-Beginners.git
```

2. Open the project folder in **Visual Studio Code** or another code editor.

3. Navigate to the project you want to explore.

4. Open the relevant `index.html` file in a web browser.

For a better development experience, you can use the **Live Server** extension in Visual Studio Code.
